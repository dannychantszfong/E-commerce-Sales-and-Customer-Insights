# E-commerce Sales and Customer Insights Analysis

## Overview
This project analyzes e-commerce sales data and customer insights to provide valuable business intelligence and actionable insights. The analysis covers various aspects including sales trends, customer behavior, product performance, and delivery metrics.

## Project Structure
```
├── Code/
│   └── data_manipulation.py      # Main analysis script
├── Data/
│   ├── olist.sqlite             # Main database file
│   ├── Monthly Sales Trend.csv
│   ├── Total Revenue.csv
│   ├── Top 10 Best-Selling Products.csv
│   ├── Top 5 Product Categories by Sales.csv
│   ├── Most Valuable Customers.csv
│   ├── Customer Purchase Frequency.csv
│   ├── Average Delivery Time.csv
│   └── Payment Methods Usage.csv
└── E-commerce Sales and Customer Insights Analysis.docx  # Detailed analysis report
```

## Data Description
The project uses various datasets that provide insights into different aspects of the e-commerce business:

1. **Sales Data**
   - Monthly sales trends
   - Total revenue metrics
   - Product performance analytics

2. **Customer Data**
   - Customer purchase frequency
   - Most valuable customer segments
   - Payment method preferences

3. **Product Data**
   - Top selling products
   - Popular product categories
   - Product performance metrics

4. **Operational Data**
   - Delivery time analytics
   - Payment processing information

## Key Features
- Comprehensive sales trend analysis
- Customer segmentation and behavior analysis
- Product performance evaluation
- Payment method usage analysis
- Delivery time tracking and analysis

## Requirements
To run the analysis scripts, you'll need:
- Python 3.x
- Required Python packages:
  - pandas
  - numpy
  - sqlite3
  - matplotlib/seaborn (for visualizations)

## Usage
1. Clone the repository
2. Ensure all required Python packages are installed
3. Run the analysis scripts from the Code directory:
   ```bash
   python data_manipulation.py
   ```

## Results
The analysis results are stored in various CSV files in the Data directory and are summarized in the comprehensive analysis document "E-commerce Sales and Customer Insights Analysis.docx".
